# SQL HR Analysis Project

## Overview
This project demonstrates foundational SQL skills using an employee dataset:
- CREATE TABLE
- INSERT INTO
- SELECT queries
- Filtering
- Aggregations

## Dataset
- name
- department 
- salary 
- hire date

## Tools Used
- SQLite
- Visual Studio Code
- GitHub

## Sample Business Questions
- What is the average salary by department?
- Who are the highest paid employees?
- How many employees were hired after 2021?

## Key SQL Skills Demonstrated
- SELECT queries
- Filtering with WHERE
- Sorting with ORDER BY
- Aggregations with COUNT and AVG
- GROUP analysis

## How to Run
1. Run setup.sql
2. Run queries in analysis_queries.sql
